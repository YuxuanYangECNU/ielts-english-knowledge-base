# 阅读 · 按套题复盘

## 套题记录（新 → 旧）

暂无已核对的整套阅读错题记录。后续按“来源 → Test → Passage → 题号”新增；每题可链接到已有的[阅读错题集](../../reading/mistakes/README.md)详解。

## 记录格式

**标题：** 剑雅册数 · Test · Reading，或软件名 · 题库／试卷名。下面记录练习日期、Passage、题型及错因概览。

| Passage / 题号 | 我的答案 → 正确答案 | 主错因 | 原文依据与思路修正 | 词汇／详解 |
| :--- | :--- | :--- | :--- | :--- |
| 待录入 | 待核对 | 待判断 | 定位句、同义替换或证据边界 | [错题词汇](../vocabulary.md) |

True / False / Not Given 等判断题先核实证据边界，避免把“没找到”直接当作 Not Given。原有错题集的详解仍保留答案折叠显示；整套复盘只放必要的简短摘要。
