# 听力 · 按套题复盘

## 套题记录（新 → 旧）

暂无已核对的整套听力错题记录。提供题目来源、日期、错题号和作答后，在这里追加对应套题；若只有错题号，答案与具体错因留“待核对”。

## 记录格式

**标题：** 剑雅册数 · Test · Listening，或软件名 · 题库／试卷名。下面记录练习日期、Section、得分（有完整答题记录时）及错因概览。

| Section / 题号 | 我的答案 → 正确答案 | 主错因 | 具体证据与下次做法 | 词汇 |
| :--- | :--- | :--- | :--- | :--- |
| 待录入 | 待核对 | 待判断 | 听到的线索、干扰转折或书写问题 | [错题词汇](../vocabulary.md) |

同一题再次做错时在原条目追加日期和本次表现；听写练习仍按[听力场景词汇](../../listening/README.md)与[听写正确率](../../listening/dictation-scores.md)记录，不和真题成绩混算。
