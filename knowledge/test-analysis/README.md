# 真题错误分析

每做完一套题，先记下**题目来源、错题号和真实错因**，再把值得复习的词汇汇总。剑雅真题和软件题库分别标明来源；无法确认的信息暂不猜测。

## 每次记录什么

**来源（剑雅册数／Test／Section 或 Passage，或软件与题库名称） → 日期 → 错题号 → 我写的答案／正确答案 → 主错因 → 一句话复盘 → 值得积累的词汇。**

题号按原卷保留；同一套题重做时注明日期，更新已有条目并保留复错记录。暂未核实的答案写“待核对”，不当作已确认错题。

### 错因分类

| 类型 | 可用标签 | 判断依据 |
| :--- | :--- | :--- |
| 答案书写 | 拼写、单复数、词形、格式／字数要求、大小写* | 听到或找到了答案，但写法或作答格式有问题 |
| 词汇理解 | 生词、熟词僻义、同义替换 | 词义或改写关系没有认出来 |
| 听力理解 | 连读弱读／辨音、定位遗漏、干扰项、信息关系 | 没听清、跟丢、被改口或相近信息带偏 |
| 阅读理解 | 定位偏差、句法／指代、逻辑判断、证据不足、题型策略 | 找错位置、看错关系或超出原文推断 |
| 做题过程 | 审题、时间分配、粗心／抄写 | 明白材料，但执行时出错；写具体表现 |

*大小写先核对评分规则；若答案本身可接受，不记为真实错题。一个题可以注明次要原因，统计时只按主错因计一次。*
