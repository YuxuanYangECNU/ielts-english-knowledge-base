# Speaking Topics · 口语主题

只保留能用进回答的词汇与句式；按话题学习，写出自己的表达。

## Topic index

- [People & Relationships](people-and-relationships.md) — relationship terms, personality language and natural ways to describe people

## Topic pattern

Keep each topic compact and use this order only when useful:

1. **核心词汇 / Core vocabulary** — grouped logically; high-value active vocabulary first.
2. **核心句式 / Speaking patterns** — natural ways to turn the vocabulary into answers.
3. **★ My version** — the user's own refined sentences when available.
4. **补充表达 / Extra useful expressions** — only a few additional patterns or words that add real value.

> The study material is only a source. Do not import every word, relationship, example or exercise from a page.

Sentence patterns and usable answers matter more than long lists of kinship terms or adjectives. Ask the user to produce their own sentence when that helps learning, then refine it before storing it.

Useful personal experiences and refined answers belong with the relevant topic, when the user has shared them.
