<div class="speaking-hub-note" markdown="1">

**Navigation rule:** entering **Speaking** must land on this hub first. `Accumulation` and `Practice` are the only two parallel primary branches.

- New learned topics belong under **Accumulation → Topics** and are added only when actually studied.
- Practice opens a second hub where the learner chooses **Chat / Free Voice / ChatGPT Voice** directly.
- Do not insert an extra `Voice` layer between `Practice` and the two voice modes.
- Practice output stays in **Practice Accumulation** and is never merged automatically into the main Accumulation area.
