# Speaking Hub · 口语总览

**Purpose:** keep active topic learning and real speaking practice clearly separated, while preserving only high-value, reusable IELTS language.

## Structure

```text
Speaking
├── Accumulation
│   └── Topic pages added only when actually studied
│
└── Practice
    ├── Voice
    │   ├── ChatGPT Voice
    │   └── Free Voice
    ├── Chat
    │   └── Free Chat only
    └── Practice Accumulation
        ├── Voice Accumulation
        └── Chat Accumulation
```

## Entry points

- **[Accumulation · 主动积累](../speaking-topics/README.md)** — topic pages added only when actually studied.
- **[Practice · 实战](practice/README.md)** — Voice, Free Chat and session-by-session practice reviews.

### Accumulation · 主动积累

- Add topics only when they are actually studied.
- `People & Relationships` is one topic, not a permanent structural category.
- Do not pre-build a full IELTS topic taxonomy.
- Keep sentence patterns, personal usable language and Band-7-oriented expression ahead of vocabulary quantity.

### Practice · 实战

Before changing the Voice / Chat workflow, session storage, review structure or Practice Accumulation, read:

**[Speaking Practice Rules · 口语实战规则](PRACTICE_RULES.md)**

Key principle:

> **Practice output must not be merged automatically into the main Accumulation area.**

Practice sessions generate their own concise session records under **Practice Accumulation**, separated into Voice and Chat.

## Story principle

Use genuine experiences, interests and opinions. Do not invent personal stories or create rigid scripts for memorisation.

When a real experience is worth keeping for active learning, connect it to flexible IELTS use:

**topic → real material → core story → useful language → Part 1 / 2 / 3 extensions**

For practice-session stories, follow `PRACTICE_RULES.md` and keep them inside the corresponding session recap unless the user explicitly chooses to move them elsewhere.
