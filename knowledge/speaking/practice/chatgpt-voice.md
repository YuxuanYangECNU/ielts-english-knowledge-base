## Workflow

1. Select one recent Mainland China IELTS Speaking topic.
2. Practise naturally in English using ChatGPT Voice.
3. End with **“结束今天的练习”**.
4. Review the transcript with GPT-5.6 Sol · Instant and keep only high-value IELTS learning points.
