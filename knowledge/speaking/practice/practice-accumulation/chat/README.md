# Chat Accumulation · 文字实战积累

Completed Free Chat sessions appear here after **End practice**. Only concise, high-value learning material is kept; the raw conversation is not archived.

The recap should not be limited to correcting mistakes. When the conversation contains genuine useful material, also retain reusable personal stories, examples, opinions, interests, useful expressions and the IELTS topics they can support. Never invent details that the learner did not actually say.
